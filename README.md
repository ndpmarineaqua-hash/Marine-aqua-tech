# Marine Aqua Tech

Flutter starter app for Android + iOS.

## Included in this prototype
- Splash screen
- Mobile OTP-style login UI
- Home dashboard
- Product catalogue
- Product details
- My Ponds
- Add Pond form
- Water Parameters
- Pond Diary
- Technical Support
- Bottom navigation

## Run
1. Install Flutter SDK.
2. Run `flutter pub get`
3. Run `flutter run`
4. For Android: `flutter build apk --release`
5. For iOS (macOS + Xcode): `flutter build ios --release`

This version uses local demo data. Firebase, real OTP, cloud database,
push notifications, dealer maps, payments/orders, and admin authentication
can be connected in the next development phase.
